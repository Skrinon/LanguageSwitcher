# Language Switcher для Windows 11

Умный переключатель раскладки клавиатуры и помощник при наборе текста для Windows 11 (аналог Caramba Switcher / Punto Switcher) с открытым исходным кодом на **C# (.NET 8, WPF + Win32 API)**.

Работает в системном трее и помогает исправлять текст, набранный в неверной раскладке, механические опечатки и случайные заглавные буквы без необходимости удалять и перепечатывать текст.

---

## Быстрая установка (готовый `.exe`)

1. Откройте раздел [**Releases**](../../releases/latest) на GitHub.
2. Скачайте автономный файл **`LanguageSwitcher.exe`**.
3. Запустите скачанный `LanguageSwitcher.exe` — **установка .NET Runtime и дополнительные файлы не требуются** (все офлайн-словари и 16 языков интерфейса уже встроены внутрь `.exe`).

> Все пользовательские настройки (`settings.json`, `user_dictionary.json`, `ignored_words.json`, `autoreplace.json`, `app_blacklist.json`, `statistics.json`) сохраняются рядом с `LanguageSwitcher.exe` (или автоматически в `%AppData%\LanguageSwitcher\`, если программа запущена из папки без прав на запись).

## Основные возможности

### 1. Ручное и автоматическое переключение раскладки (`EN` ⇄ `RU` ⇄ `UA`)
- **Двойное быстрое нажатие `Left Alt`** (`≤ 350 мс`):
  - Если выделен текст — конвертирует выделенный фрагмент.
  - Если текст не выделен — исправляет последнее набранное слово или выполняет **умный откат (Smart Undo)** последнего автоматического исправления.
  - При выборе 3 и более языков (`English`, `Русский`, `Українська`) циклически переключает раскладку по кругу.
- **Автопереключение при наборе:** автоматически распознаёт, что слово набрано в ошибочной раскладке, по встроенным офлайн-словарям (по 60 000 словоформ для каждого языка) и переводит слово в нужную раскладку после ввода разделителя (пробел, Enter, знаки препинания).
- **Гибкий выбор исходного языка:** автоопределение раскладки по символам или приоритетный исходный язык по умолчанию.

### 2. Исправление механических опечаток (не Т9) и двойных заглавных
- **Клавиатурный алгоритм опечаток:** учитывает физическое расположение соседних клавиш (горизонталь, вертикаль, диагональ), перестановку соседних букв (`приевт` → `привет`), двойные нажатия (`внезщапные` → `внезапные`) и пропуски букв при скоростной печати.
- **Защита ненормативной лексики и сленга:** встроенный фильтр с учётом приставок предотвращает случайную замену мата или сленга на созвучные обычные слова.
- **Исправление второй случайной заглавной буквы:** автоматически превращает `ПРивет` → `Привет`, `HEllo` → `Hello`, не трогая аббревиатуры (`NATO`, `CS2`, `ПРИВЕТ`) и стилизованные названия (`iPhone`).

### 3. Пользовательские списки, автозамены и словари
- **Пользовательский словарь и импорт:** добавление собственных слов с привязкой к языку и асинхронный импорт файлов `.txt`, `.dic`, `.csv` с автоопределением кодировки (`UTF-8`, `UTF-8 BOM`, `Windows-1251`).
- **Слова-исключения:** слова, которые алгоритм никогда не будет менять.
- **Автозамена и сниппеты:** мгновенная замена коротких триггеров (например, `спс` → `спасибо`) с сохранением регистра и поддержкой многострочного текста.

### 4. Исключения для программ и игр
- **Чёрный список программ (`.exe`)** и **автопауза в полноэкранных играх/приложениях** (активируются при включении соответствующей настройки, по желанию можно также блокировать ручной двойной `Left Alt`).

### 5. Аналитика, профиль и интерфейс Windows 11
- **Статистика и экономия времени:** подсчёт количества переключений раскладки, исправленных опечаток, двойных заглавных, автозамен и оценочно сэкономленного времени.
- **Экспорт и импорт профиля:** резервное копирование всех настроек и списков в один `.json`-файл с поддержкой режимов объединения и перезаписи.
- **16 языков интерфейса:** `ar`, `de`, `en`, `es`, `fr`, `hi`, `it`, `ja`, `ko`, `nl`, `pl`, `pt`, `ru`, `tr`, `uk`, `zh` (включая поддержку RTL для арабского языка) с переключением без перезапуска.
- **Системный трей и автозапуск Windows:** сворачивание в область уведомлений Windows 11 и опциональный автозапуск вместе с системой (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).

## Сборка из исходного кода

Требования: **Windows 10 / 11 (x64)** и **.NET 8.0 SDK**.

```powershell
# Клонирование репозитория
git clone https://github.com/<your-username>/LanguageSwitcher.git
cd LanguageSwitcher

# Обычная сборка в конфигурации Release
dotnet build LanguageSwitcher.csproj -c Release

# Сборка автономного однофайлового LanguageSwitcher.exe
dotnet publish LanguageSwitcher.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o ReleaseSingleFile
```

## Структура проекта

- `Models/AppSettings.cs` — модели настроек, профилей, статистики и языкового каталога.
- `Services/KeyboardHookService.cs` — глобальные хуки клавиатуры/мыши (`WH_KEYBOARD_LL` / `WH_MOUSE_LL`), определение скорости набора и двойного `Left Alt`.
- `Services/LayoutConverter.cs` — конвертация символов между раскладками `EN` / `RU` / `UA` и циклическое переключение.
- `Services/DictionaryService.cs` — офлайн-словари, оценка автопереключения, исправление двойных заглавных и взвешенная матрица опечаток.
- `Services/ProfanityFilterService.cs` — защита ненормативной лексики и сленга.
- `Services/AutoReplaceService.cs` — таблица автозамен с сохранением регистра.
- `Services/AppExclusionService.cs` — проверка чёрного списка процессов и полноэкранного режима.
- `Services/UsageStatisticsService.cs` — подсчёт статистики исправлений и сэкономленного времени.
- `Services/LocalizationService.cs` — динамическая локализация на 16 языков.
- `Services/ProfileBackupService.cs` — экспорт и импорт резервной копии профиля.
- `Dictionaries/` — встроенные частотные словари (`en.txt`, `ru.txt`, `uk.txt`) и словарь фильтра (`profanity_filter.txt`).
- `locales/` — JSON-файлы локализации интерфейса.
